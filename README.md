# ✨ AURA Creative Studio

**AURA Creative Studio** is a modern AI-powered image generation platform that transforms simple text prompts into stunning visual artwork. It combines AI-powered prompt enhancement, image generation, creative styles, personalized galleries, and social features into one complete creative workspace.

> 🎨 **Turn your imagination into visual art with AI.**

---

## 🚀 Features

### 🤖 AI-Powered Image Generation

Generate unique images from natural-language text prompts using AI.

### ✨ Intelligent Prompt Enhancement

Improve simple prompts with AI to create more detailed, creative, and visually rich generation instructions.

### 🎨 Multiple Creative Styles

Create artwork in different visual styles and experiment with different artistic directions.

### 📐 Multiple Aspect Ratios

Generate content for different use cases with support for multiple aspect ratios.

### 🖼️ Personal Gallery

View and manage your previously generated artwork from a centralized gallery.

### ❤️ Favorites

Save your favorite generations for quick access later.

### 🌐 Public Gallery

Share selected artwork publicly and explore creations generated by other users.

### 👍 Likes & Views

Public artwork can receive likes and track views.

### 📝 Generation History

Keep track of prompts and previously generated artwork.

### 💾 Persistent Database

Neon PostgreSQL is used to persist generations, favorites, prompt history, and related application data.

### 🔄 Local Storage Fallback

The application includes a local JSON persistence fallback so the application can continue operating even when the external database is unavailable during development.

### 📱 Responsive Design

Designed to provide a smooth experience across desktop, tablet, and mobile devices.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate into the project:

```bash
cd aura-3d-ai-creative-studio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY="your_gemini_api_key"

APP_URL="http://localhost:3000"

DATABASE_URL="your_neon_postgresql_connection_string"

STORAGE_PROVIDER="local"
```

### Environment Variables

| Variable           | Description                                     |
| ------------------ | ----------------------------------------------- |
| `GEMINI_API_KEY`   | Google Gemini API key used for AI functionality |
| `APP_URL`          | Application URL                                 |
| `DATABASE_URL`     | Neon/PostgreSQL connection string               |
| `STORAGE_PROVIDER` | Storage provider such as `local`                |

> ⚠️ **Never commit your `.env` file or API keys to GitHub.**

---

## ▶️ Run the Application

Start the application with:

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:3000
```

## 🗄️ Database

AURA Creative Studio uses **Neon PostgreSQL** for persistent application data.

The application automatically initializes the required tables:

```text
generations
favorites
prompt_history
```

The `generations` table stores information such as:

* User
* Prompt
* Enhanced prompt
* Generated image URL
* Style
* Aspect ratio
* Quality
* Creation date
* Favorites
* Public status
* Likes
* Views
* Source type

If Neon is unavailable, the application can fall back to local JSON persistence.

## 🔐 Security

The project uses environment variables to protect sensitive credentials.

Do not expose:

```text
GEMINI_API_KEY
DATABASE_URL
Database passwords
```

Do not upload `.env` to GitHub.

Add the following to `.gitignore`:

```gitignore
.env
.env.local
.env.production
.data/
node_modules/
```

If an API key or database password is accidentally exposed, revoke or rotate it immediately.
